# EarlETF 图表周刊 · 指标看板

> **在线看板（点开即可用）**：<https://wj624.github.io/earl-etf-dashboard/>  
> **五年之锚 v2（独立页）**：<https://wj624.github.io/earl-etf-dashboard/anchor_v2.html>  
> **源码仓库**：<https://github.com/wj624/earl-etf-dashboard>

复现张翼轸《EarlETF 图表周刊》中的图表模型，做成一个**自包含单文件看板**，数据每天自动更新。
页面把「A 股/红利/成长价值」的估值、资金、情绪指标集中在一屏，用来判断**当前处在周期的什么位置**。

- 手机、电脑都可以直接打开，支持「添加到主屏幕」当 App 用
- 单文件自包含：ECharts 与数据全部内联，**离线也能看**，不依赖任何外部 CDN
- 全站最新数据日会显示在页面顶部，每张图右上角各有自己的「数据截止日」

## 二、页面怎么读

1. **先看顶部「数据截止」**：每张图的数据源发布节奏不同（有的 T+0、有的 T+5），
   页面会为滞后的图单独标注「沿用最近可得数据」及其日期，不会被最新日掩盖。
2. **看分位而不是看绝对值**：所有指标都给历史分位，80% 以上和 20% 以下才是有意义的信号区。
3. **交叉验证**：单一指标（比如只看估值低）容易误判，估值 + 情绪 + 资金三条线同向时结论才可靠。
4. **不用手动刷新**：页面加载时先拉几十字节的 `version.txt`，与线上版本一致就直接用缓存，
   不一致才重新下载 `data.json`（跨境链路下 `data.json` 有 2MB，这一步设计省了很多等待）。

## 四、口径与替代说明（重要）

中证官网只提供**价格指数**，且部分标的没有公开日频源。页面「口径与替代说明」一栏逐条披露，这里列出要点：

- **M1 / M3 / M10**：原文用全收益指数，本页用价格指数 → 收益与偏离度**系统性偏低约每年 2%**（股息缺口）。
  M10b 已改用官方全收益指数 H00922 消除此偏差。
- **M3**：原文用万得偏债混合型基金指数（Wind 专有）→ 用 `25% 沪深300 + 75% 中证债券基金指数` 合成。
- **M5**：原文用万得一级债基指数 → 改用中证债券基金指数（H11023），基日同为 2007-12-31。
- **M7**：国证成长100 / 价值100（980080 / 980081）无公开历史源 → 改用国证成长(399370) / 国证价值(399371)。
- **M8**：中证红利日频股息率官方只给最近 20 天（每日累积）；长周期曲线用上证红利按
  「派息率 ÷ 滚动市盈率」反推，**属估算**。
- **M2**：受免费 PE 源限制，股债性价比为**月频**。
- **M14**：2010 年以前的担保比例部分为估算段。

> 看到红色「估算」标记的图，请把它当趋势参考，不要当精确值用。

## 五、自动更新

**每天 18:30（北京时间）自动更新一次。**

```yaml
# .github/workflows/update.yml
schedule:
  - cron: '30 10 * * *'   # 10:30 UTC = 18:30 北京时间
```

工作流做的事：装依赖 → 判断缓存充不充足（`cache/csi*.csv` ≥ 15 个走 `--quick` 增量模式）→
跑 `fetch_data.py` → 跑 `build.py` 打包 → 提交 `index.html data.json data.js version.txt cache/`。
内容没有变化时自动跳过提交，不会刷空 commit。

### 想改更新时间？

改上面那行 cron 即可。换算规则：**北京时间 − 8 小时 = UTC**。

| 想要的时间 | cron 写法 |
|---|---|
| 每天 18:30（当前） | `30 10 * * *` |
| 每天 20:00 | `0 12 * * *` |
| 仅在周一至周五 18:30 | `30 10 * * 1-5` |
| 每天 18:30 和次日 08:00 各一次 | `30 10 * * *` + `0 0 * * *` |

> cron 用 UTC，且受 GitHub 调度拥挤影响可能延后几分钟，属正常现象。

### 为什么原作者停用了云端定时任务，这里却能开？

原作者在 2026-09-18 主动注释掉了 schedule，注释里写明了原因——**本机与云端双写互相覆盖**：

1. 云端 checkout 仓库里的 `template.html` 重建 `index.html`，覆盖了本机用新版模板推出的完整版 → 页面出现「数据补充中」空白卡；
2. 云端不提交 `version.txt`，前端版本探针读到旧版本号 → 误判「已是最新」，问题被锁死。

本仓库是**云端单写**：没有任何本机计划任务往这里推，`template.html` 与 `index.html` 永远由同一次构建产出，
因此不存在上述冲突；并且本工作流的提交已包含 `version.txt`，版本探针能正常推进。

## 六、本地运行

```bash
pip install -r requirements.txt   # requests numpy pandas（另需 akshare）
python fetch_data.py --quick      # 增量快跑，日常用这个
python build.py                   # 打包成自包含 index.html
```

全量回补历史（首次或缓存缺失时用，耗时较长、会被中证官网 WAF 限流）：

```bash
python fetch_data.py              # 不加 --quick 即全量
python backfill.py 2              # 中证官网补洞守护进程，最多跑 2 小时
```

## 七、文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | **构建产物**：自包含单文件看板（ECharts + 数据已内联，双击即可打开） |
| `anchor_v2.html` | 独立页：五年之锚 v2（Wind全A 偏离率交易区间），也是自包含单文件 |
| `template.html` | 页面源码。**要改页面改这里**，改完必须跑 `build.py` |
| `build.py` | 把 `template.html` + `echarts.min.js` + `data.js` 打包成 `index.html`，并写 `version.txt` |
| `fetch_data.py` | 数据抓取 + 20 个指标计算，输出 `data.json` / `data.js` |
| `official.py` | 官方利率源：中债登国债收益率曲线、美国财政部国债收益率 |
| `backfill.py` | 中证官网历史补洞守护进程（应对 WAF 限流） |
| `cache/` | 本地数据缓存（CSV，断点续传）。**勿删**，删了要全量重抓 |
| `echarts.min.js` | 本地 ECharts 源文件（构建时内联） |
| `version.txt` | 版本探针，内容 = `data.json` 的 updated 时间 |
| `.github/workflows/update.yml` | 每日自动更新工作流 |

## 八、维护须知

1. **`cache/` 目录不要删。** 里面有 2005 年以来的指数历史，中证官网有 WAF 限流，重抓一次要很久。
2. **改页面只改 `template.html`，改完一定要跑 `build.py`。** 直接改 `index.html` 会被下次构建覆盖。
3. **改动后如果页面出现「数据补充中」空白卡**，通常是 `template.html` 与 `index.html` 不同步，
   跑一次 `python build.py` 即可。
4. 提交内容里必须包含 `version.txt`，否则前端版本探针会卡在旧版本。
