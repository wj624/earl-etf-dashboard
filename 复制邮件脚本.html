✅ 已复制到剪贴板。现在去 Apps Script 编辑器，先全选（Ctrl+A）删掉原来的空 myFunction， 再粘贴（Ctrl+V），然后 Ctrl+S 保存。
贴进去之后按这个顺序做
  1. 打开 script.google.com/home → 打开你已有的项目（第一次用就点左上「新项目」，项目名建议叫 A股每日解读）
  2. 把上面这段代码全部粘进去，覆盖掉原来的内容（新项目里是默认的 myFunction），Ctrl+S 保存
  3. 第一次运行任何函数都会弹授权：点「高级」→「前往项目（不安全）」→「允许」。 这是 Google 对未验证脚本的通用拦截，不是报错
  4. 设置两个密钥（只需一次，都不写进代码）。文件里已经有一个现成的 setupKeys()， 把两个空引号换成你的密钥：
    setGeminiKey('AIza...你的Gemini密钥');  // 39 位，AIza 开头
    setFredKey('355d...你的FRED密钥');  // 32 位
    申请地址：Gemini 去 aistudio.google.com/apikey， FRED 去 fredaccount.stlouisfed.org/apikeys。
    改完在顶部下拉里选 setupKeys 运行 → 看到两条 ✅ 已保存…（39 位）/（32 位） → 再把两个密钥删回空字符串 '' → Ctrl+S
    ⚠️ 不要直接选中 setGeminiKey / setFredKey 运行 —— 它们是带参数的函数，直接运行等于没传参，只会打印用法、什么都不会保存
  5. 选 keyDiag → 运行，核对：探针能写能读，两个密钥都显示「…（39 位）/（32 位）」
  6. 选 testConnections → 运行，看三条链路（数据源 / FRED / Gemini）是不是都 ✅
  7. 选 previewNow → 运行，去邮箱看效果（没收到先翻垃圾邮件箱）
  8. 选 installDailyTrigger → 运行，装上每天 19:15 的定时器 （会先清空本项目原有触发器，重复跑是安全的）
  9. 点左侧闹钟图标「触发器」，确认有一条 dailyMain / 时间驱动 / 每天 / 下午 7 点~8 点
数据源地址已经写好，不用改。想改收件人、发信时间、开关 AI，只动文件顶部的 CONFIG。
代码里没有密钥，这是故意的。本页的脚本会提交到公开仓库，如果把 Gemini / FRED 密钥写进代码， Google / FRED 的扫描器会扫到并判定「泄露」，直接永久作废 （Gemini 报错 403 Your API key was reported as leaked）。 密钥一律用 setupKeys() 存进「项目设置 → 脚本属性」，存完再把密钥从代码里删掉。
另：脚本属性是「项目级」的。换一个新的 Apps Script 项目，密钥全是空的； 定时器也只挂在具体项目上 —— 如果两个项目都装了 dailyMain，你会收到两封邮件， 点「触发器」删掉多余的那个。
本页每次打开都直接从仓库拉取最新的 gas-earl-daily.gs， 所以永远和仓库里的版本一致，不会出现“本地是旧的”这种情况。
